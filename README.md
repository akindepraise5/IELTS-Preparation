# IELTS Practice Room

A single-page IELTS Academic study site: practice tests, strategies, lessons and a progress tracker.

## Sections

- **Progress**: band per section over time, accuracy by question type, a "what to work on next" list, and a form to log scores from real tests (Cambridge IELTS 1–19, ielts.org, IELTS Ready).
- **Listening**: Part 1 practice with 10 questions, read aloud by the browser's built-in voices, with auto-marking and a band estimate.
- **Reading**: one passage with 13 questions, a timer, text highlighting and explained answers.
- **Writing**: Task 1 (bar chart) and Task 2 prompts, with a word counter, timer, saved drafts and a self-rating form.
- **Speaking**: Part 1–3 questions and a Part 2 preparation and speaking timer.
- **Learn**: 17 short lessons with quick checks, plus links to free official resources.
- **Strategies**: step-by-step methods for all 12 Reading question types.

All questions and lessons are original practice material written in the IELTS format. They are not real past papers.

## Running it

Open `index.html` in a browser. There is no build step and nothing to install.

To host it, enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main` / root).

## Where your data is saved

Outside Claude, progress, lesson completion and writing drafts are saved in the browser's local storage. They stay on that device and browser only, and clearing site data erases them.
